3. Materi: Scratch dan Pictoblox

A. Apa itu pemrograman visual?

Pemrograman visual menyusun instruksi menggunakan blok yang saling terhubung. Bentuk blok membantu pemula mengenali struktur program tanpa harus menghafal banyak sintaks. Scratch sering digunakan untuk membuat animasi, cerita, dan permainan; Pictoblox memiliki pendekatan blok yang serupa dan dapat mendukung proyek AI, perangkat keras, serta IoT sesuai ekstensi/perangkat yang digunakan.

C. Kelompok blok dan fungsi

MOTION / GERAKMemindahkan objek, mengubah posisi x-y, mengatur arah, meluncur.
LOOKS / TAMPILANMengubah kostum, ukuran, efek, menampilkan atau menyembunyikan objek.
EVENTS / KEJADIANMemulai skrip saat bendera hijau diklik, tombol ditekan, atau pesan diterima.
CONTROL / KONTROLMenunggu, mengulang (repeat/forever), serta membuat percabangan if atau if-else.
SENSING / SENSORMendeteksi tombol, sentuhan, jarak, atau kondisi masukan lain yang tersedia.
OPERATORS / OPERATOROperasi matematika, perbandingan, serta logika AND, OR, NOT.
VARIABLES / VARIABELMenyimpan nilai, misalnya statusLampu = 1 (menyala) atau 0 (mati).
MY BLOCKS / BLOK BUATANMembuat prosedur sendiri agar skrip lebih rapi dan dapat digunakan kembali.

E. Algoritma dan pseudocode

MULAI
atur semua lampu = MATI
selama program berjalan:
  jika tombol 1 dipilih, ubah status Lampu 1
  jika tombol 2 dipilih, ubah status Lampu 2
  jika tombol 3 dipilih, ubah status Lampu 3
SELESAI saat pengguna menekan tombol berhenti

Algoritma di atas menggunakan kejadian (event) dan percabangan. Dalam proyek sebenarnya, setiap tombol dapat mengubah satu variabel status, lalu tampilan lampu diperbarui sesuai nilai variabel tersebut.

F. Scratch dan Pictoblox: persamaan dan perbedaan

AspekScratchPictoblox
DasarBlok visual untuk animasi, cerita, dan game.Blok visual dengan alur mirip Scratch.
PenggunaanSprite, panggung, event, kontrol, variabel.Blok visual, serta fitur tambahan melalui ekstensi yang didukung.
Perangkat keras / AIMemerlukan ekstensi atau integrasi tertentu.Dapat mendukung sejumlah perangkat dan fitur AI sesuai versi, ekstensi, dan perangkat.
Prinsip pemrogramanKeduanya menggunakan urutan, event, percabangan, perulangan, operator, dan variabel.
Ingat: susunan blok harus logis. Periksa event pemicu, kondisi, nilai variabel, dan urutan instruksi jika hasil program tidak sesuai harapan.
